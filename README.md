# Iyappan A — Game Art & VFX Portfolio

A responsive, self-contained portfolio website built with HTML, CSS and vanilla JavaScript. It has no package install or build step.

## Run it

Double-click `start-portfolio.cmd` on Windows to open a local preview with the playable YouTube embed enabled. Opening `index.html` directly still shows the portfolio, with a link to the playlist instead of an embed. The site can also be uploaded to any static web host.

## Update the content

- Edit `portfolio.js` to change the bio, skills, project titles and descriptions, credits, experience, education, services and contact details.
- The embedded YouTube playlist is in the `showreel` section of `index.html`.
- The header and footer brand image is `assets/neon-star-graffiti-logo.png`.
- Replace images in `assets/` and update the matching `image` paths and `alt` descriptions in `portfolio.js`.
- The portrait is `assets/iyappan-portrait.jpg`.
- Update the page title and summary in the `<head>` of `index.html` when publishing under a final domain.

Project content and imagery were adapted from Iyappan’s supplied portfolio PDF. The contact email, phone, location and professional links come from the supplied resume and portfolio. Personal date-of-birth and other non-portfolio details were left out.

## Files

- `index.html` — page content and navigation
- `styles.css` — visual design, responsive layout and reduced-motion support
- `portfolio.js` — editable portfolio data
- `app.js` — content rendering, mobile navigation and subtle reveal animations
- `assets/` — portrait and project images
